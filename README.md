# Наш Клининг — сайт

Готовый адаптивный сайт компании по уборке и химчистке. Размещается на GitHub Pages без сборки.

## Что внутри
- Каталог услуг и интерактивный прайс в BYN, перенесённый с присланных скриншотов.
- Анимации, плавные градиенты, стеклянные блоки и мобильная адаптация.
- Форма заказа через WhatsApp: номер +375 29 660-14-41.
- Карта городов на OpenStreetMap/Leaflet: Минск, Бобруйск, Солигорск, Жлобин, Рогачёв.
- Блоки преимуществ, вопросы и ответы, фотографии-направления и ссылки на Instagram.

## Запуск
Откройте `index.html` в браузере. Для публикации: **Settings → Pages → Deploy from a branch → main / (root)**.

## Важно
Перед запуском проверьте актуальность цен по оригинальным прайсам. Уточнения по объёму работ и степени загрязнения оставлены на сайте. 
Фотографии услуг используются иллюстративно (Unsplash), не выдаются за реальные работы. Для публикации замените их собственными.
Фирменный логотип `assets/logo.png` извлечён из присланного скриншота; лучше заменить оригиналом в высоком разрешении.
Заявки не сохраняются на сервере, а открывают WhatsApp с заранее заполненным сообщением.

Для изменения номера телефона найдите в `index.html` строку `375296601441`.
